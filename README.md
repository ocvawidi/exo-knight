# Exo Knight

A hybrid workspace for the Exo Knight roleplay project.

## Project approach

- **Notion** is the working space for planning, discussion, and evolving notes.
- **GitHub** stores versioned project specifications, schemas, tests, and approved lore.
- **ChatGPT/runtime** uses the available project context to facilitate roleplay while preserving player agency and continuity.

## Canon governance

Lore must be labeled with one of these statuses:

- `CANON` — explicitly approved by the creator.
- `PROVISIONAL` — a working interpretation that may change.
- `PROPOSED` — an idea awaiting approval.
- `UNKNOWN` — not established; do not invent it as fact.

Only the creator can approve new canon. Do not silently retcon established facts, and do not decide the player's actions, dialogue, choices, or private thoughts for them.

## Initial status

This repository is being initialized. Character details and world lore should be imported from verified project material rather than invented during setup.

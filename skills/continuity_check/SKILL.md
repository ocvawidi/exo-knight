# Skill: Continuity Check

Status: PROVISIONAL workflow specification. A runtime must explicitly load and implement it.

## Use when
Reviewing a scene, recap, character action, or proposed lore change for consistency.

## Checks
- Timeline: do dates, sequence, and elapsed time agree?
- Location: can the characters plausibly be where the scene places them?
- Character knowledge: how did each character learn the relevant fact?
- Capabilities: are powers, tools, and limitations supported by sources?
- Relationships: does the interaction conflict with established relationship facts?
- State: do injuries, equipment, resources, and commitments persist correctly?
- Player agency: did the narration decide something reserved for the player?
- Canon status: did a proposal or improvisation become canon without approval?

## Report format
- PASS: no material issue found.
- WARNING: possible issue or insufficient source evidence.
- CONFLICT: direct contradiction with a cited source.
- Recommended resolution: ask, revise, or label as proposed.

Do not silently rewrite canon to make a scene fit.

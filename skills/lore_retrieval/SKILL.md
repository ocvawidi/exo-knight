# Skill: Lore Retrieval

Status: PROVISIONAL workflow specification. A runtime must explicitly load and implement it.

## Use when
A scene or answer depends on established world, character, technology, or timeline facts.

## Procedure
1. Search the available project sources for the specific entity or question.
2. Prefer creator-approved canon and authoritative source material.
3. Record source and canon status for each important fact.
4. Compare potentially conflicting entries.
5. Return only the context needed for the current task.
6. Mark missing facts UNKNOWN; do not infer them as canon.
7. If sources conflict materially, surface the conflict and request a decision.

## Suggested retrieval record
- Fact
- Status
- Source
- Relevant date/version
- Confidence or unresolved conflict

## Guardrails
A matching name is not proof that a fact is canon. Repetition is not approval. Never fabricate a source.

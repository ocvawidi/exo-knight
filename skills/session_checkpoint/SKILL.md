# Skill: Session Checkpoint

Status: PROVISIONAL workflow specification. A runtime must explicitly load and implement it.

## Use when
The player asks to save, summarize, pause, or prepare a session handoff.

## Include
- Session identifier or title, if known.
- Current scene and approximate in-world time, if known.
- Confirmed events in chronological order.
- Active characters and their current states.
- What each important character knows, where known.
- Open threads, promises, threats, and pending decisions.
- Unresolved contradictions and unknown facts.
- Proposed lore awaiting creator approval.
- Last player action and the point where play should resume.

## Do not
- Convert every improvised detail into permanent canon.
- Invent a timestamp, location, or character state.
- Resolve an open thread without evidence.
- Write future actions or decisions for the player.

Label the checkpoint as a session record, not a canon document, unless the creator separately approves canon changes.
